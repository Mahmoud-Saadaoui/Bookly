## 🚀 QUICK START

### Start Using It Right Now (3 steps)

**Step 1: Install Backend**
```bash
cd backend
npm install
npm run dev
```

**Step 2: Install Frontend** (new terminal)
```bash
cd frontend
npm install
npm start
```

**Step 3: Test It**
1. Open http://localhost:3000
2. Login to your account
3. Go to any book details page
4. Click "Loan This Book" button
5. Select dates in the calendar
6. Click "Confirm Loan"
7. Done! 🎉
